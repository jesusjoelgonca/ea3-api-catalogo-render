API JSON

Los mismos datos están disponibles en JSON para su reutilización:

  • GET /api/productos — catálogo completo; admite ?marca=Samsung, ?q=galaxy, ?min_precio=300&max_precio=800 y ?orden=precio_asc|precio_desc|calificacion|resenas|nombre.
  • GET /api/productos/B0GW9TVHJB — un producto por ASIN.
  • GET /api/metricas — resumen del mercado, agregados por marca, distribución por tramo de precio y top de calificación.
  • GET /healthz — estado del servicio y versión desplegada.
